# Projektübersicht – HTML-App

## Zweck

Bestehende HTML-Anwendung, die direkt im Obsidian-Vault gespeichert und dort bearbeitet wird. Obsidian verwaltet Wissen und Dokumentation, der Code liegt in `Anwendung/`.

## Aufbau

| Pfad | Inhalt |
| --- | --- |
| `Anwendung/index.html` | die bestehende Anwendung (noch nicht eingesetzt) |
| `Anwendung/assets/` | Bilder, Fonts, Medien |
| `Anwendung/css/` | Stylesheets (für spätere Aufteilung) |
| `Anwendung/js/features/` | Funktionsmodule (für spätere Aufteilung) |
| `Dokumentation/` | [[02_Projekte/HTML-App/Dokumentation/Funktionen|Funktionen]], [[02_Projekte/HTML-App/Dokumentation/Bedienungsanleitung|Bedienungsanleitung]], [[02_Projekte/HTML-App/Dokumentation/Fehler|Fehler]], [[02_Projekte/HTML-App/Dokumentation/Technische-Notizen|Technische Notizen]] |
